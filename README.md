# PHP CLI Dungeon Crawler

Minigame built with **PHP 8.2+** and **Symfony Console**. 

Players navigate a procedurally generated array maze, avoid Mimics, defeat Orcs and unlock chests to conquer all levels.

---

## Prerequisites

Make sure you have installed:
* **PHP 8.2+**
* **Composer**
* **Git**

---

## Quick Start

### 1. Clone the repo
```bash
git clone https://github.com/MatousKuchar01/Array_Hunt.git
cd array_hunt
composer install
php bin/console app:play
