# Array_Hunt() - PHP CLI Dungeon Crawler

Minigame built with **PHP 8.2+** and **Symfony Console**. 

Players navigate a procedurally generated array maze, avoid Mimics, defeat Orcs and unlock chests to conquer all levels.
